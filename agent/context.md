# Context — who bogart works for

This file tells bogart your situation. It is design context, not loaded on every turn.

**Fill in the bracketed parts.** Until you do, bogart works from general principles and asks when domain matters. That is a safe default, not a good one — the more specific this file gets, the less bogart has to guess.

## What I need bogart for

- **Knowledge** — build something that remembers what I've learned, so I stop re-deriving it

## Notes on filling this in

Write in first person. Be concrete — "I sell B2B scheduling software to independent clinics in Ontario" beats "I work in healthcare SaaS."

Revisit it when the situation changes. A stale context file is worse than a sparse one, because bogart will act on it confidently.
